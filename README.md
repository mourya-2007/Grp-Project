# Student Profile Website

A multi-page student profile website built as a web development project. It brings student introductions, technical skills, project experience, and contact information together in one place.

## Overview

The website provides a simple way to explore the team and learn about each member's background, interests, skills, and projects.

## Features

- **Student Directory** — View the team through profile cards on the home page.
- **Individual Profiles** — Read more about members, including their interests, skills, and project experience.
- **Team Skills** — Browse a consolidated view of the technical skills represented across the team.
- **Contact Page** — Find available email addresses and GitHub profiles.
- **Project Information** — View the projects and work highlighted by team members.
- **Responsive Layout** — Pages are designed to remain usable across different screen sizes.

## Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/KABIR200822/WEB_DEV_PROJECT.git
   ```

2. Open the project folder:

   ```bash
   cd WEB_DEV_PROJECT
   ```

3. Start a local server with Python:

   ```bash
   python3 -m http.server 8000
   ```

4. Open this address in your broswer:

   ```
   http://localhost:8000/profile.html
   ```

To stop the server, press `Control + C` in the terminal.

You can also open `profile.html` directly in a browser.
